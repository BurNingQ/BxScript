# Array 数组

BxScript 数组为可变长度的有序值集合，通过数字索引访问。

## 属性

| 属性 | 类型 | 描述 |
|:-----|:-----|:-----|
| `length` | Number | 数组元素个数 |

## 创建与访问

```javascript
let arr = [1, 2, 3];
arr[0];         // 1
arr[1];         // 2
arr.length;     // 3
arr[5] = 99;    // 自动扩展，中间元素为 null
```

## 方法

### `push(item1, item2, ...)`
向数组末尾添加一个或多个元素。

| 参数 | 类型 | 描述 |
|:-----|:-----|:-----|
| `item...` | any | 要添加的元素 |

| 返回值 | 描述 |
|:-------|:-----|
| Number | 添加后的数组长度 |

```javascript
let arr = [1, 2];
arr.push(3);       // 返回 3，arr = [1, 2, 3]
arr.push(4, 5);    // 返回 5，arr = [1, 2, 3, 4, 5]
```

### `pop()`
移除并返回数组最后一个元素。

| 返回值 | 描述 |
|:-------|:-----|
| any / Null | 被移除的元素，空数组返回 `null` |

```javascript
let arr = [1, 2, 3];
arr.pop();  // 3，arr = [1, 2]
```

### `shift()`
移除并返回数组第一个元素。

| 返回值 | 描述 |
|:-------|:-----|
| any / Null | 被移除的元素，空数组返回 `null` |

```javascript
let arr = [1, 2, 3];
arr.shift();  // 1，arr = [2, 3]
```

### `unshift(item1, item2, ...)`
向数组开头插入一个或多个元素。

| 参数 | 类型 | 描述 |
|:-----|:-----|:-----|
| `item...` | any | 要插入的元素 |

| 返回值 | 描述 |
|:-------|:-----|
| Number | 插入后的数组长度 |

```javascript
let arr = [3, 4];
arr.unshift(1, 2);  // 返回 4，arr = [1, 2, 3, 4]
```

### `concat(arrOrVal, ...)`
合并数组或值，返回新数组，原数组不变。

| 参数 | 类型 | 描述 |
|:-----|:-----|:-----|
| `arrOrVal...` | Array 或 any | 数组会被展开一层，非数组值直接追加 |

| 返回值 | 描述 |
|:-------|:-----|
| Array | 合并后的新数组 |

```javascript
[1, 2].concat([3, 4], 5);  // [1, 2, 3, 4, 5]
```

### `join([separator])`
将数组元素连接为字符串。

| 参数 | 类型 | 描述 |
|:-----|:-----|:-----|
| `separator` | String | 可选，分隔符，默认 `","` |

| 返回值 | 描述 |
|:-------|:-----|
| String | 连接后的字符串 |

```javascript
[1, 2, 3].join();      // "1,2,3"
[1, 2, 3].join(" - "); // "1 - 2 - 3"
```

### `indexOf(item, [start])`
查找元素首次出现的位置。

| 参数 | 类型 | 描述 |
|:-----|:-----|:-----|
| `item` | any | 要查找的元素 |
| `start` | Number | 可选，起始搜索索引，默认 0 |

| 返回值 | 描述 |
|:-------|:-----|
| Number | 首次出现的索引，未找到返回 `-1` |

```javascript
[1, 2, 3, 2].indexOf(2);     // 1
[1, 2, 3, 2].indexOf(2, 2);  // 3
```

### `lastIndexOf(item, [start])`
查找元素最后一次出现的位置（从后往前搜索）。

| 参数 | 类型 | 描述 |
|:-----|:-----|:-----|
| `item` | any | 要查找的元素 |
| `start` | Number | 可选，起始搜索索引 |

| 返回值 | 描述 |
|:-------|:-----|
| Number | 最后一次出现的索引，未找到返回 `-1` |

```javascript
[1, 2, 3, 2].lastIndexOf(2);  // 3
```

### `slice([start], [end])`
截取子数组，返回新数组，原数组不变。

| 参数 | 类型 | 描述 |
|:-----|:-----|:-----|
| `start` | Number | 可选，起始索引（含），默认 0。负值表示从末尾算起 |
| `end` | Number | 可选，结束索引（不含），默认数组长度。负值表示从末尾算起 |

| 返回值 | 描述 |
|:-------|:-----|
| Array | 截取的新数组 |

```javascript
let arr = [1, 2, 3, 4, 5];
arr.slice(1, 3);   // [2, 3]
arr.slice(2);      // [3, 4, 5]
arr.slice(-2);     // [4, 5]
```

### `remove(index, [count])`
从数组中删除元素，返回被删除的元素数组。

| 参数 | 类型 | 描述 |
|:-----|:-----|:-----|
| `index` | Number | 删除起始索引 |
| `count` | Number | 可选，删除个数，默认 1 |

| 返回值 | 描述 |
|:-------|:-----|
| Array / Null | 被删除的元素数组，索引越界返回 `null` |

```javascript
let arr = [1, 2, 3, 4, 5];
arr.remove(1, 2);  // [2, 3]，arr = [1, 4, 5]
arr.remove(2);     // [5]，arr = [1, 4]
```

### `insert(index, item)`
在指定位置插入元素。

| 参数 | 类型 | 描述 |
|:-----|:-----|:-----|
| `index` | Number | 插入位置索引 |
| `item` | any | 要插入的元素 |

| 返回值 | 描述 |
|:-------|:-----|
| Number | 插入后的数组长度 |

```javascript
let arr = [1, 3];
arr.insert(1, 2);  // 返回 3，arr = [1, 2, 3]
```

## 静态方法

### `Array.isArray(val)`
检测值是否为数组。

| 返回值 | 描述 |
|:-------|:-----|
| Bool | 是否为数组 |

```javascript
Array.isArray([1, 2]);   // true
Array.isArray("hello");  // false
Array.isArray({});       // false
```
