## English

### Project Overview
This project is a **C++ port** of the [winc](https://github.com/tadvi/winc) library, which was originally written in Go. `winc` provides a high-level wrapper for the Windows API, simplifying the creation of native desktop applications.

The translation was meticulously performed by feeding the Go source files into **Google Gemini**, which assisted in refactoring and translating the logic into C++.

### Key Features
* **Go-Style Simplicity:** Ported the clean and intuitive API design from the original library.
* **Native C++ Performance:** Direct integration with Windows headers for efficient execution.
* **AI-Assisted Porting:** A demonstration of leveraging LLMs for complex cross-language library migration.

### Links & Credits
* **Original Library (Go):** [tadvi/winc](https://github.com/tadvi/winc)
* **AI Translation Partner:** [Google Gemini](https://gemini.google.com/)

## 中文

### 项目简介
本项目是 [winc](https://github.com/tadvi/winc) (Go 语言编写) 的 **C++ 移植版本**。`winc` 是一个对 Windows API 的高级封装，旨在简化原生桌面应用程序的开发。

本项目的翻译过程通过 **Google Gemini** 协作完成：将 Go 源码逐一提供给 Gemini，并由其辅助完成向 C++ 的逻辑重构与代码翻译。

### 项目特点
* **延续 Go 的简洁设计：** 完美保留了原库易用、直观的 API 风格。
* **原生 C++ 性能：** 直接调用 Windows 系统底层接口，确保运行效率。
* **AI 辅助开发：** 展示了利用大语言模型（Gemini）进行复杂跨语言库移植的实践案例。

### 相关链接
* **原版 Go 库：** [tadvi/winc](https://github.com/tadvi/winc)
* **AI 翻译支持：** [Google Gemini](https://gemini.google.com/)
